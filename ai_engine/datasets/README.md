# AI Engine Datasets Directory

This directory is designated for datasets used by Cyber Raksha AI's detection models.

## Planned Datasets (Stages 2 - 4)

1. **Phishing Email Corpora**: Nazario phishing corpus, Enron clean corpus, and synthetic spear-phishing sets.
2. **Malicious URLs**: PhishTank, URLHaus, Alexa top 1M, and benign crawl datasets.
3. **Voice Cloning / Synthetic Audio**: ASVspoof 2019/2021, FakeAVCeleb, WaveFake, and custom multilingual voice cloning samples.
4. **Suspicious Communication Logs**: SMS fraud datasets, social engineering transcripts.
5. **Threat Intelligence IoCs**: MITRE ATT&CK indicators, AlienVault OTX feeds.

> **Stage 1 Note**: No datasets are downloaded or stored during Stage 1.
